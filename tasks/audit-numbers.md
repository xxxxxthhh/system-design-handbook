## 审计范围

`index.html`、`ch01.html`–`ch16.html`、`level1.html`–`level4.html`

## 逐页检查这五类

1. **·2 原理段的公式代入**：把每一步乘除自己算一遍，确认结果与页面写的一致。
2. **自测题的计算题**：题干给的数字 → 标为 `data-k="good"` 的选项 → verdict 解析里的算式，
   三者必须完全自洽。特别注意解析里对"诱人错误选项"的解释是否算得对。
3. **指标卡 `.metric`**：卡片里的数字与正文叙述是否一致（例如正文说"命中率 2%"，
   卡片是否也是 2%）。
4. **复盘时间线**：`.timeline` / `.beat` 里的数字与开场 `.pager` 告警里的数字是否一致
   （例如开场说连接数 1498，复盘说从 1498 回落到 600，前后要对得上）。
5. **跨章引用的数字**：某章写"第 N 章算过 X"时，去 `chN.html` 确认 X 确实是那个值。

## 输出

写进 `tasks/AUDIT-numbers.md`，每行一条：

```
文件 | 位置(附近原文20字) | 页面声称 | 你的验算 | 判定
```

判定取值：`错误` / `存疑` / `正确但表述易误解`。

- **算对的不用列。** 整页无问题就写一行 `chNN ✅ 无问题`。
- 不确定的列进去标 `存疑`，由 lead 裁定。
- **不要修改任何 .html 文件**，也不要改 assets/ 或 tools/。只写这一个报告文件。
